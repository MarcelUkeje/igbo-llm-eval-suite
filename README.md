# Igbo Language QA & Localization Portfolio

This repository contains structured examples of my work in English–Igbo localization, linguistic quality assurance, AI response evaluation, and text refinement for real-world digital product contexts.

The goal is to demonstrate the ability to evaluate, adapt, and improve language used in modern software systems such as mobile apps, chat assistants, and digital platforms.

---

## Focus Areas

### 1. UI Localization (Real Product Interfaces)
Translation and adaptation of user interface text from English to Igbo while preserving clarity, tone, and usability in real app environments.

### 2. AI Response Evaluation
Assessment of AI-generated outputs for accuracy, fluency, tone consistency, and cultural relevance in practical usage scenarios (e.g. customer support, search, and assistant tools).

### 3. Proofreading & Copyediting
Improvement of existing product copy such as notifications, alerts, and in-app messages to enhance clarity and user understanding.

### 4. Prompt Evaluation
Analysis and refinement of prompts used to generate AI responses in applied contexts such as e-commerce support, travel assistance, and digital communication tools.

---

## Repository Structure

Each sample follows a consistent format:
- `source.md` → original context or system reference
- `input.txt` → original text or AI output
- `output.txt` → improved or translated version
- `notes.md` → explanation of decisions and linguistic reasoning
